# Travel Pal — Soft Flock (Chrome Theme)

Install in Chrome:

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select this folder  
   — or pack it from the extensions page / upload as a Chrome Web Store theme

Palette draws from soft sage skies, cream UI surfaces, coral accents, and quiet flock shapes — a calm travel morning feel.
