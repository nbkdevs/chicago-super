# Travel Pal — Journey Notes (Firefox)

Companion extension for jotting trip memories while browsing. Notes stay in local browser storage.

## Install

1. Open `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on…**
3. Select `manifest.json` in this folder

For permanent install, package as `.xpi` and submit to addons.mozilla.org (gecko id: `travel-pal@travelpal.app`).
