# chicago_charter_bus_rental

Dart package for **[Chicago Charter Bus Rental](https://chicagosupercoachbus.com/)**.

```dart
import 'package:chicago_charter_bus_rental/chicago_charter_bus_rental.dart';

print(chicagoCharterBusRentalTitle);
print(chicagoCharterBusRentalHomepageUrl());
```

Publish with `dart pub publish` from this directory (separate from the Travel Pal app).
